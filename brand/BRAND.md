# AdvenBook brand guide (official values, from www.advenbook.com)

These values come from the live AdvenBook site. Use them exactly. Do not invent other colors.

## Colors

| Role | Name | Hex | Use |
|---|---|---|---|
| Background | Pierre Claire | `#F8F5F0` | page background (warm off-white) |
| Text | Ardoise Doux | `#2D3748` | body text |
| Primary | Bleu Ardoise | `#1B2D45` | header, main buttons, user bubbles, links |
| Accent | Cuivre Patiné | `#D4956B` | highlights, the "Open my book" call to action, progress |
| Cards | Blanc Pur | `#FFFFFF` | cards, assistant bubbles, inputs |
| Secondary | Vert Mousse | `#3A6B5C` | success states, "Strava connected", checkmarks |
| Paper | Crème Papier | `#F4EDE4` | soft panels, the book result card background |
| Dark | Nuit Alpine | `#0C1821` | dark hero areas, text on light accent |
| Muted text | Gris Pierre | `#94A3B8` | captions, timestamps, hints |
| Borders | Gris Pierre Clair | `#E2E8F0` | borders, dividers, input outlines |

- Text on Bleu Ardoise or Nuit Alpine: Pierre Claire `#F8F5F0`.
- Text on Cuivre Patiné: white `#FFFFFF`.
- Corner radius: 8px (0.5rem) for inputs and buttons. Cards may use 12–16px.
- Errors: a plain red (`#EF4444`), used sparingly.

## Fonts (Google Fonts, via `next/font/google`)

- Headlines: **Playfair Display** (serif, elegant, like the printed book).
- Body and UI: **Inter**.

## Logos (in this folder)

- `logo_advenbook.svg`: the main logo (vector). Prefer it.
- `logo_icone.png`: the square icon (favicon, avatar of the agent in the chat).
- `logo_nom.png`: the wordmark.

The logos are AdvenBook trademarks.

## Feel

Warm outdoor premium: calm slate blue, patinated copper, stone and paper tones, large photos, clean and readable pages, never cluttered.
